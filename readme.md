🌦️ Weather App

A modern, responsive weather application built with HTML, CSS and Vanilla JavaScript.

The application provides real-time weather information, forecasts and dynamic visual themes that adapt to current weather conditions.

✨ Project Overview

This project aims to create an interactive weather experience with three distinct visual themes:

- ☀️ Sunny: Warm colours, bright backgrounds and sun-inspired animations.
- 🌧️ Rainy: Cool blue tones, atmospheric backgrounds and falling rain animations.
- 🌬️ Windy: Fresh mint and teal colours with wind-inspired animations.

The interface automatically adapts to the weather conditions retrieved from the API.

🚀 Features

Core Features

- City-based weather search.
- Real-time weather information.
- Current temperature and weather conditions.
- Humidity and wind speed.
- Feels-like temperature.
- Hourly weather forecast.
- Five-day weather forecast.

UI & Experience

- Three dynamic weather themes.
- Weather-based animations.
- Responsive mobile-first design.
- Smooth transitions.
- Loading indicators.
- Error handling.

Additional Features

- Current location weather.
- Celsius/Fahrenheit conversion.
- Last searched city persistence.

Features will be implemented progressively during development.

🌐 Weather API

Weather information is provided by "Open-Meteo" (https://open-meteo.com/).

The application uses:

- Geocoding API for city searches.
- Forecast API for current weather.
- Hourly forecast data.
- Daily forecast data.

📱 Responsiveness

The application is designed with a mobile-first approach and will support:

- Mobile devices.
- Tablets.
- Desktop screens.
